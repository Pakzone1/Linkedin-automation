# LinkedIn Lens runtime

This folder contains the Manifest V3 extension source. Load it directly for development. Store ZIPs are built from the repository root with `npm run package` and include runtime files only.

See the repository README, `docs/USAGE.md`, `PRIVACY.md` and `store/SUBMISSION.md` for setup, data handling and publishing. AI processing requires explicit consent and the user's own OpenRouter key. There is no bundled key or local topic classifier.
