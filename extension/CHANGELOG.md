# Changelog

## 1.0.0

First public release of LinkedIn Lens.

- AI classification with 60 editable categories across three levels.
- Reversible category masks with visible reasons and one-click reveal.
- Ad and promotion labels, manual corrections, and non-post card detection.
- Analysis of visible posts and the next 10 loaded posts.
- Optional editable comment drafts with Copy and Insert.
- Explicit cloud-processing consent, trusted key storage and request controls.
- Chrome / Edge Manifest V3 support, automated checks and reproducible release packages.
